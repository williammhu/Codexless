Running `node test/installer-lifecycle-windows.mjs` prints its explicit non-Windows skip. **Production Windows installer execution: NOT RUN (Linux host).** A Linux fixture result cannot establish that PowerShell execution policy or the production installer will succeed on Windows.

Patch 02 only changes `package.json` and the corresponding generated manifest; the inherited fix remains separate from patch 01's PR follow-ups. That pre-existing behavior is unchanged, and artifact inclusion alone is not a Windows uninstall lifecycle certification.
